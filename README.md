# maoshu_Calendar

基于 **ESP32-C3 + 2.4 寸 ST7789 屏** 的横屏桌面时钟（320×240）。一块小板子当桌上摆件：看时间、农历黄历、天气，也能收作业提醒、做番茄钟、定闹钟。

> 本项目为个人 DIY 项目，硬件为安信可 Core-ESP32（ESP32-C3）开发板 + 2.4 寸 SPI 串口屏，焊接与接线说明见下。

---

## 功能

| 功能  | 说明                                                                                                     |
| --- | ------------------------------------------------------------------------------------------------------ |
| 桌面  | 插画壁纸做背景，右侧深色信息面板：星期、大时钟、农历、今日天气与最高温、黄历宜忌（宜绿忌红），面板底部小字显示当前 IP                                           |
| 备忘录 | 巴法云 MQTT 或同一局域网网页推送，断电保留最近 10 条；**新推送排第一页最前**；单条上限 600 字节，推送后自动跳到备忘录页，翻页靠按键                                          |
| 天气  | Open-Meteo 免费接口（无需密钥），7 天预报页；失败自动退避重试                                                                  |
| 番茄钟 | 专注/短休/长休自动循环，时长可在网页配置；阶段结束有蜂鸣提示音                                                                       |
| 闹钟  | 最多 4 组，每天或仅一次，到点间歇响 60 秒，任意按键停止                                                                        |
| 壁纸  | 内置 5 套 320×240 插画壁纸，壁纸页可启用/停用与切换                                                                       |
| 配置页 | 设备内置 Web 配置，分两页：`/` 常用设置（番茄钟→闹钟→局域网备忘录表单），`/sys` 系统设置（网络→天气地区→巴法云推送）                                   |
| 字库  | 16×16 宋体，约 3,800 个常用汉字（GB2312 一级 + 常用补充）及常用符号（← ↑ → ↓、①~⑩、Ⅰ~Ⅻ、℃ ％ ° √ × ≥ ≤ ～【 】等）；长箭头 ⟶ 与 emoji 仍显示方框 |

## 硬件清单

| 物料  | 规格                                               |
| --- | ------------------------------------------------ |
| 主控  | 安信可 Core-ESP32（ESP32-C3，USB Type-C，4MB Flash）    |
| 屏幕  | 2.4 寸 ST7789 240×320 IPS，10PIN SPI 串口屏 + FPC 转接板 |
| 按键  | 轻触开关 1 个（接 GPIO8，代码内部上拉）                         |
| 蜂鸣器 | 有源蜂鸣器 1 个（正极 → GPIO6，负极 → GND）                   |
| 其他  | 杜邦线若干、5V USB 供电                                  |

## 接线（已实测）

屏幕 10PIN 转接板 → ESP32-C3：

| 孔位  | 屏幕功能    | ESP32-C3 |
| --- | ------- | -------- |
| 1   | GND     | GND      |
| 2   | RESET   | GPIO5    |
| 3   | SCL     | GPIO2    |
| 4   | D/C     | GPIO4    |
| 5   | CS      | GPIO7    |
| 6   | SDA     | GPIO3    |
| 7   | BLK（背光） | 3.3V（常亮） |
| 8   | VCC     | 3.3V     |

- MISO 不接（屏只写）；SPI4W 引脚接 GND
- 按键：一脚 GPIO8，另一脚 GND
- 蜂鸣器：正极 GPIO6，负极 GND
- 注意：**不要按屏幕丝印字面理解 SDA/SCL**，以上表为准；杜邦线 SPI 频率用 27MHz，过高会花屏

## 编译与烧录

Arduino IDE 2.x + esp32 核心包（2.0.17-cn），开发板选 **ESP32C3 Dev Module**。

必选参数：

| 设置              | 值                     |
| --------------- | --------------------- |
| PartitionScheme | Huge APP (3MB No OTA) |
| Flash Frequency | 40MHz                 |
| Flash Mode      | DIO                   |
| USB CDC On Boot | Enabled               |

arduino-cli 一键编译：

```powershell
arduino-cli compile `
  --fqbn "esp32:esp32:esp32c3:PartitionScheme=huge_app,FlashFreq=40,FlashMode=dio,CDCOnBoot=cdc" `
  --build-path "$env:TEMP\maoshu_build" `
  "./maoshu_Calendar"
```

烧录前需让板子进下载模式（按住 BOOT → 短按 RST → 松开 BOOT），否则报 `Wrong boot mode detected (0xc)`。

依赖库：**TFT_eSPI**（需用本项目的 `User_Setup.h` 覆盖，并打 ESP32-C3 补丁，详见《maoshu_Calendar_开发与使用说明.md》第五节）、**PubSubClient**、**OneButton**。

## 首次使用

1. 上电进入配网模式：手机连热点 `maoshu_Calendar` / `12345678`
2. 浏览器打开 `192.168.4.1`，选择 WiFi 并输入密码，保存重启
3. 联网后屏幕上会出现约 10 秒的启动信息页（版本号 + 设备 IP），也可按任意键直接进入桌面；桌面右侧面板底部同样显示 IP
4. 用同一局域网的浏览器访问 `http://设备IP/` 进入配置页

配置页分两页，顶部可互相切换，当前页高亮：

- `/` **常用设置**：番茄钟 → 闹钟 → 局域网备忘录（表单直接内嵌）
- `/sys` **系统设置**：网络 → 天气地区 → 巴法云推送

除网络外都即时生效并存入 NVS；各表单保存后回到对应页面并给出提示。

## 按键手势

| 操作     | 桌面   | 备忘录                                      | 番茄钟   | 天气   | 壁纸    |
| ------ | ---- | ---------------------------------------- | ----- | ---- | ----- |
| 单击     | 进备忘录 | 下一页（末页回到第 1 页）                            | 开始/暂停 | 返回桌面 | 换下一套  |
| 双击     | 进天气  | 上一页（第 1 页回到末页）                            | 重置    | —    | 启用/停用 |
| 三击     | 进壁纸  | 回到第 1 页（最新内容）                             | —     | —    | —     |
| 长按 3 秒 | —    | 弹出操作菜单：单击退出回桌面 / 双击进入清空确认 | 回桌面   | 返回桌面 | 回桌面   |

- 备忘录页翻页为循环：0 条或只有 1 页时，单击/双击/三击都不跳页。
- 长按菜单 8 秒无操作自动关闭；菜单内三击或再长按取消。进入清空确认后，再长按一次才真正清空，单击/双击取消。
- 连击判定窗口 300ms；闹钟响铃期间任意按键立即静音。

## 壁纸替换

`maoshu_Calendar/wallpapers/` 放原图，运行电脑端工具重新生成并编译：

```bash
python tools/wallpaper_convert.py --day maoshu_Calendar/wallpapers/1.png --out maoshu_Calendar/wallpaper_data.h
```

每套壁纸 153,600 B（320×240 RGB565，仅白天版）。

## 局域网推送备忘录（推荐）

设备与手机在同一个 WiFi 下时，用手机浏览器打开配置页首页：

```
http://设备IP/
```

- 页面最下方的「局域网备忘录」区块可直接输入并提交，与巴法云走同一套入库/存储逻辑，断电保留最近 10 条。
- 单条上限 **600 字节**（约 200 个汉字）；按 UTF-8 实时显示“已用 XX/600 字节”，超限变红并禁止提交，后端也会拒绝超长内容。
- 提交成功后屏幕自动跳到备忘录页第 1 页（最新内容）；新推送始终排在第一条，旧内容依次后移。页内翻页只由按键触发，不会自动翻页。
- **清空**：网页点「清空全部备忘录」（需 `confirm` 确认）；设备端在备忘录页长按 3 秒弹出菜单，双击菜单进入清空确认，再长按一次才执行，单击/双击可取消。只删除备忘录条目，不影响闹钟、番茄钟、天气与巴法云设置。
- 页面内已说明：同一局域网内任何能访问该设备的手机/电脑都可写入，公共网络请勿使用。
- 旧地址 `/memo` 仍可用，会自动跳回 `/`。

## 巴法云推送（可选）

在 [bemfa.com](https://bemfa.com) 注册后取得私钥 UID 与主题，填入配置页即可，无需重新编译。源码 `common.h` 中为占位符 `youUID` / `yourTopic`，**请勿提交真实私钥**。
